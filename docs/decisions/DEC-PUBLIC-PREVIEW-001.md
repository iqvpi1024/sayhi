## 决定

1. 以 MIT 许可证公开 `v0.1.0-synthetic-preview` 的源代码和发布资产。
2. 该版本只允许合成演示数据；不承诺或宣传真实个人资料生产可用性。
3. 公开交付级别为 D1：从源码或发布资产一键建立本地合成演示。D2/D3 中涉及签名安装包、升级、真实数据与普通用户生产部署的要求仍未完成。
4. `Noetide` 仅作为项目名称，不主张已注册商标或域名权利。

## 依据与边界

依据 PRD §2.3、§6、§17、§21.4、§24.1、§24.7 与 §27.1。MIT 便于审计和可移植性，但不改变用户数据所有权、Source/Canonical/Derived 分离或本地优先原则。

本决定不裁决未来商业版、品牌注册、应用商店、签名证书、真实数据许可或 D2/D3 发布流程。它只解除当前公开合成预览的 `DQ-005` 阻塞。
